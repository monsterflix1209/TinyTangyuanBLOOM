# WATCHTVarr

## 🎮 Play
Open `index.html` in a modern browser, or enable GitHub Pages for the repository and open the published site.

## Current game loop
- Multi-round living-room adventure
- Exploration and collectible interactions
- Risk / progress systems
- Consequence choice
- Reflection quiz
- User-written confession
- Score and final report

## Local run
Because the project is static, it can be served by any static web host. For local testing, use a simple static server so local assets load consistently.

## Art policy
Do not copy proprietary characters, logos, screenshots, or artwork from commercial games. Use original WATCHTVarr art or assets with redistribution rights, and keep source/license notes for third-party assets.
