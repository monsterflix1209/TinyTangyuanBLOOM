# WATCHTVarr Asset Sources

## Goal
Use legally reusable assets while the original Canva asset pipeline is unavailable.

## Sources
- Kenney — https://kenney.nl/assets — many packs are CC0; verify the individual pack license before redistribution.
- OpenGameArt — https://opengameart.org/ — licenses vary; verify each asset's license and attribution requirements.
- itch.io free game assets — https://itch.io/game-assets/free — licenses vary; verify each pack before use.

## Project rule
Do not copy characters, logos, screenshots, or proprietary artwork from commercial games. WATCHTVarr should use original code/art direction plus assets whose individual license permits redistribution.

## Integration
Assets used by the game should live under `assets/` and be referenced locally by the HTML/JS. Keep a source and license note for each third-party asset.
